Radio

Presets region, modem preset, frequency slot, channel and hop limit together. Private test uses the standard LongFast radio settings a stock node understands, but with a channel name and key only your node holds, so nobody else decodes your synthetic nodes. The public entry targets the shared default channel and carries a warning.

--

Slot selection is djb2 over the channel name, not the header channel hash. It is never computed in this page: the value shown is whatever the backend reports for the current region, preset and channel name.

Channel

An empty name expands to the preset display name in firmware.

One-based, matching loraConfig.channel_num. Leave empty to derive the slot from djb2 of the channel name, which is what a stock node does. A config that pins a slot lands on a different frequency than the name would choose, and nothing reports the mismatch.
